# TinyFish Browser for Android
Native Android browser app with URL/search, back/forward/reload, and multiple tabs. This first installable app uses Android System WebView, **not Gecko/Firefox**, and does not yet include AI-driven page automation or a configurable automation API.

## Build
Open this folder in Android Studio or download the `tinyfish-browser-debug-apk` artifact from the GitHub Actions workflow after it succeeds.
Minimum Android version: Android 8.0 (API 26).
